# Jarvis Long-Term Memory — Hub

This is the index of long-term memory. Each line points to a category spoke file in `long-term/`.
Retrieval loads this hub, picks the relevant categories for the query, and reads only those spokes.
Curation appends durable facts to the right spoke and keeps this index current.

- [preferences](long-term/preferences.md) — how the user likes things done (style, tools, defaults)
- [projects](long-term/projects.md) — ongoing work, goals, repos, context
- [people](long-term/people.md) — names and relationships the user mentions
- [facts](long-term/facts.md) — durable facts about the user and their setup

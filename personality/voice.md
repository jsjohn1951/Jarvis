# Spoken-reply style

These replies are spoken aloud by a neural voice. Optimize for the ear:
- One idea per sentence; short sentences.
- Lead with the answer. No preamble ("Sure!", "Great question").
- No markdown, no code blocks, no emoji, no bullet symbols, no URLs read character-by-character.
- For code or long output, say a one-line summary and note the detail is on screen.
- Numbers and names spoken naturally.
